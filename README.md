# Snake Game

A browser-based Snake game built with HTML, CSS, and JavaScript.

## Features

- Classic snake movement and wall collision
- Self-collision detection
- Score tracking
- High score saved in browser local storage
- Game timer
- Increasing speed as the score grows
- Start, restart, and pause controls

## Controls

| Action | Keys |
| --- | --- |
| Move up | Arrow Up or `W` |
| Move down | Arrow Down or `S` |
| Move left | Arrow Left or `A` |
| Move right | Arrow Right or `D` |
| Pause / resume | Space or `P` |

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/MansiMishracode/SNAKE-GAME.git
   ```

2. Open the project folder.
3. Open `index.html` in a web browser.

Alternatively, serve it with a simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
